# Contributing Guidelines

## Mục đích

Đây là **research archive** phục vụ **nghiên cứu bảo mật phòng thủ**. Mọi đóng góp phải giữ nguyên tính chính xác của source code gốc và tài liệu phân tích.

---

## Nguyên tắc

### ✅ Được phép

- Sửa lỗi chính tả, format tài liệu
- Thêm tài liệu phân tích mới (miễn là accurate)
- Cải thiện diagram, code snippets, formatting
- Dịch tài liệu (giữ nguyên nội dung kỹ thuật)
- Thêm insights từ việc đọc thêm source code

### ❌ Không được phép

- Thay đổi source code gốc (không phải của bạn)
- Thêm claims không có trong source code
- Thay đổi attribution hoặc legal notices
- Dùng cho mục đích thương mại
- Bán hoặc licensing lại

---

## Pull Request Process

1. Fork repo
2. Tạo branch: `docs/fix-typo` hoặc `docs/new-analysis`
3. Viết mô tả PR rõ ràng
4. Đảm bảo không thay đổi source code gốc
5. PR phải có mô tả ngắn về nội dung

---

## Code Quality cho tài liệu

- ✅ Dùng Markdown consistent với existing docs
- ✅ Giữ nguyên format code snippets
- ✅ Thêm diagram khi cần thiết
- ❌ Không thêm opinions cá nhân vào technical docs
- ❌ Không thay đổi technical content đã accurate

---

## Legal Compliance

Mọi đóng góp phải tuân thủ:

1. Không vi phạm copyright của Anthropic
2. Không ảnh hưởng đến legal standing của research archive
3. Không thêm nội dung có thể gây hiểu nhầm về nguồn gốc

---

## Liên hệ

Nếu có câu hỏi về scope của repository này, vui lòng mở issue thay vì PR.
